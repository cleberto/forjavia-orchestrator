# Origem e separação do Core

Forjavia aplica capacidades genéricas de governança: autoridade explícita, escopo, evidência, verificação independente e avanço por gates. Instâncias de projeto podem fornecer domínio, fontes e regras próprias sem promovê-las ao Core.

A arquitetura v1.3 descreve Forjavia como um único Control Plane. Provedores de especificação, qualidade, inteligência de código e execução permanecem substituíveis. Regras mecânicas migram para validação determinística; decisões de produto e julgamento continuam explícitos.

Fontes históricas específicas de projeto não fazem parte do repositório genérico. O Core publica apenas mecanismos reutilizáveis e sua documentação própria.

Qualquer incorporação futura de material externo exige inventário do conteúdo efetivo, licença/proveniência e testes de compatibilidade. Não há autoridade implícita para copiar arquivos de um projeto para o Core.
